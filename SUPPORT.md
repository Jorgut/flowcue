# Support

Reroute 0.1.x supports Apple silicon Macs running macOS 14 or later. It requires a signed-in Codex CLI version that provides the `queue` command.

## Before reporting a problem

1. Confirm that the Codex CLI runs and is signed in.
2. Confirm that `codex queue` is supported by the installed CLI version.
3. Restart Reroute from the current application path so an older copy does not retain the global shortcut.
4. Keep the original idea in Reroute when delivery is reported as unknown; do not queue it again until the Codex task is checked.

## Get help

Use [GitHub Issues](https://github.com/Jorgut/reroute-codex/issues) for reproducible bugs and feature requests. Include the Reroute version, macOS version, Codex CLI version, expected behavior, and actual behavior.

Do not post idea text, task identifiers, authentication information, local file paths, or raw Codex logs in a public issue. Report security-sensitive problems through the private process described in [SECURITY.md](SECURITY.md).
