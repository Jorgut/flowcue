# 冒烟测试（macOS）

冒烟测试只回答一个问题：**装上能不能跑**。不测细节、不测边界。
任何一条失败就停——冒烟不过，功能测试没有意义。

## 自动部分

```bash
zsh Scripts/smoke.sh          # 用现有 build
zsh Scripts/smoke.sh --build  # 先打包再测
```

脚本做四件事：

| 检查 | 方法 |
|---|---|
| 四个窗口能打开 | `--args -inbox / -settings / -agents / -panel` 逐个启动，查 CGWindowList 是否有可见窗口 |
| 退出干净 | 结束后 `pgrep` 应为空 |
| 没有崩溃 | 最近 10 分钟的 `DiagnosticReports` 数量为 0 |

最近一次结果：

```
✅ 收件箱：1 个可见窗口
✅ 设置：1 个可见窗口
✅ 本机 Agent：2 个可见窗口
✅ 捕获面板：1 个可见窗口
✅ 退出干净
✅ 最近 10 分钟无崩溃
—— 通过 6 · 失败 0 ——
```

> 依赖生成物（图标 `Support/*.icns` 等）。干净 checkout 里先跑
> `zsh Scripts/build-app.sh`，否则图标测试会跳过（见 `IconAssetTests`）。

## 人工部分（三条，约 2 分钟）

| # | 操作 | 期望 |
|---|---|---|
| 1 | ⌃⌥Space → 写一句话 → ⌘↩ | 面板关闭，收件箱里出现这条想法 |
| 2 | 收件箱右上角切三种布局 | 都能切，列表和详情不串位 |
| 3 | 菜单栏图标右键 → 退出 | 菜单栏图标消失，无残留进程 |

第 2 条重点看**左栏是否从顶部开始**（曾因 HStack 垂直居中而整体下移）。
