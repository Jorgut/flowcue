方案 A：一份中立正文 + 软链

~/.agents/skills/strategic-compact/SKILL.md （唯一副本）
“Use your agent’s compact command after long phases…”
↳~/.cc-switch/skills/strategic-compact symlink
↳~/.claude/skills/strategic-compact symlink
↳~/.codex/skills/strategic-compact symlink
↳~/.config/opencode/skills/strategic-compact symlink
收益
改一次全平台生效；审计里这组从「分叉」变成「一致」。
改之前（每个平台各一份）
- Use the Codex compact command after long phases
- Use the Claude compact command after long phases
改之后（一份，各平台都成立）
+ Use your agent’s compact command after long phases
（命令、步骤、触发条件都不变，只去掉平台名）
