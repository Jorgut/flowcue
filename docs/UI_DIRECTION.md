# FlowCue UI 方向

> 状态：图标与角色**已定稿并落地**；面板与收件箱为**方向稿**，尚未实现。
> 定稿日期：2026-11-13
> 适用：macOS 14+ 菜单栏应用。iOS 版本待独立设计。

---

## 1. 设计原则

1. **输入是唯一锚点。** 面板上最重的元素是输入区，其余全部退后。
2. **一切无边框。** 层级靠留白、字号、透明度，不靠卡片和描边。
3. **一个强调色。** 品牌色可换（主题），语义色固定。
4. **状态由元素承载。** 角色、光标、按钮颜色都在表达状态，不额外加标签。
5. **验证靠像素，不靠眼睛。** 几何结论都要能用数值核对。

## 2. 颜色

### 2.1 品牌 / 交互色（可主题化）

| token | 值 | 用途 |
|---|---|---|
| `accent` | `#7E84FF`（图标）/ `#8A90FF`（小尺寸） | 主操作、光标、选中态 |
| `accent-soft` | 14% 透明 | chip、高亮底 |
| `accent-on` | `#0A0A18` | 强调色上的文字 |

| token | 值 | 含义 |
|---|---|---|

| `status-warn` | `#F0B429` | 待确认 |
| `status-bad` | `#FF5C5C` | 失败 |
| `status-muted` | 白 40% | 草稿、已归档 |

**规则**

1. 主题只改表面、描边、文字、强调色、圆角、字体、氛围；**不改布局、不改组件结构**。
2. 语义色随主题微调，但必须保持"成功=绿、警告=黄、失败=红"的可辨识度，**不能复用强调色当状态色**。
3. 默认 Airy Dark；Neutral 与 Blueprint 免费，其余 5 个走 Pro 解锁（入口：Me → Appearance）。
4. macOS 复用同一批 token；AppKit 端圆角统一 ×0.85 后取整。
5. 主题 ID 与显示名分离（`airy` / "Airy Dark"），便于以后加主题不改代码。

| 项 | 值 |

- 纵向：墨迹中心 53 / 52.6，比画板中心低约 5 —— **已确认接受**，不整体上移。

### 4.5 动效

| 唤起 | 图标归位成脸，眨眼三次 | 240ms + 3×100ms |
| 输入中 | 眼睛随手移动 | — |
| 提交 | 眯眼 + 笑弧，箭头点亮 | 200ms |
| 已排队 | 得意笑 | 持续 |
| 关闭 | 收回成图标 | 240ms |
| Reduce Motion | 只保留淡入 | — |

### 4.6 话筒（语音记录）

角色的竖杠接过来当话筒头，加一双"光标变的脚"。数值以 200×200 画布为准，等比放大。

| 部件 | 尺寸 | 对位 |
|---|---|---|
| 身体 | 48 × 84，r24 | 上下留 40 / 76，中线 x=100 |
| 眼睛 | 10 × 13，r5 | y=51，两眼间距 14，成对居中 |
| 嘴 | 10 × 6 | y=74，说话时高度 2→10 往复（每秒 4 次） |
| 双脚 | 22 × 11 × 2，r5.5 | 间距 4，总宽 48 = 身体宽，平放不倾斜，y=126 |

五态：待机 / 按下（收 5% + 双环）/ 说话（只动嘴，身体不动）/ 换气（眼睛眯）/ 失败（红描边 + 感叹号，3s 回待机）。

**尺寸规则**：≥32pt 画脚；20–31pt 只画身体 + 眼睛；<20pt 只有胶囊。


### 4.7 启动动效（待定）

图标 → 笑脸 → 得意笑 → 眨眼 → 复位，串成无限循环。**结论未定**，2026-11-14 当天的尝试整体归档在
`Design/UIExplorations/_archive/process-2026-11-14/`。

已确认、可直接沿用的部分：

| 项 | 结论 |
|---|---|
| 图标零件归属 | 光标竖杠 → 鼻子；回车横杠 → 笑弧；人字头淡出 |
| 得意笑 | **抬 10**（R 20.89），圆心沿 P0 法线移动，左嘴角切线不变 |
| 眼睛 | 在固定位置睁开；眯缝用**圆角短线**（18.4 × 3.2），不用压扁椭圆 |
| 慢眨 | 三下，每下约 470ms |
| 复位 | 沿原轨迹倒放；眼睛先闭合并消失，不含在倒放里 |
| 图标几何 | 见 §3.1；矢量以 `construct-icon-v2.html` 为准 |

未定：竖杆收回与横杠弯曲的先后比例、以及复位时“横杠变直”那一段的过渡方式。


## 5. 捕获面板（方向稿）

### 5.1 结构

一张 composer，分四层，后两层条件显示：

1. 结构：顶行（面包屑 + 收件箱 + 关闭）、正文、底行（`＋` / 目的地 chip / 发送）
2. 上下文：最近任务 + 状态（有数据才显示）
3. 模板：空草稿时三枚 chip
4. 角色：头部 22–24px；空状态 54–56px

### 5.2 目的地

- 默认「收件箱」—— 守住"默认只存本地"
- 改为 Codex 任务时，chip 与按钮同时变强调色
- 目的地 chip 点开 = 分组面板（置顶 / 最近 / 全部）

| Pair | 二维码或 8 位码，与 Mac 端同一串 |
| Lab | 实验开关（默认关）+ 提建议入口 |
| Feedback | 问题/建议/崩溃 + 描述 + 截图 + 诊断日志 |

**导航**：Ideas / Agents / Me 三项。搜索放在 Ideas 下拉，归档作为筛选，设置并入 Me。

**会话切换**：Chat 标题「Codex ⌄」点开底部 sheet，直接切换会话，不必返回列表。

**Chat 右上角 ···**：重命名、清空、断开设备、设备信息。

### 9.2 状态矩阵（27 态）

| 页面 | 状态 |
|---|---|
| Home | 默认 / 空 / 加载 / 同步失败 / 离线 |
| Agents | 默认 / 发现中 / 无 agent / 连不上 / 离线 |
| Sessions | 默认 / 空 / 加载 / 加载失败 |
| Chat | 会话 / 空 / 发送中 / 发送失败 / 离线 |
| Remote | 已连接 / 配对中 / 配对失败 / 已断开 |
| Me | 默认 / 同步失败 / 离线 / Pro 过期 |

首页滚动：搜索框常驻，筛选 chips 在下滚 > 12pt 时收起（200ms）、上滚或回顶时滑回（240ms）；列表不让位。

规则：红色＝失败、黄色＝等待/离线、绿色＝正常；每种异常都有出路（Retry / Reconnect / Cancel / Pair）；同步失败时本地数据仍然可见。

### 9.3 流程

- **配对**（5 步）：选择设备 → 输入 6 位码 → 连接中 → 成功 / 失败（码过期）
- **分享扩展**（3 态）：分享表单（可改目的地）→ 已保存 → 离线也能存
- **付费墙**（3 屏）：Pro 介绍 → 主题解锁 → 已开通

### 9.4 动效

| 动作 | 时长 | 曲线 |
|---|---|---|
| 眨眼 | 90ms × 3 | ease-in-out |
| 发送回执 | 收起 240ms，停留 1.6s | spring(0.35, 0.85) |
| 捕获 Sheet | 320ms | spring(0.34, 0.86) |
| 页面推入 | 300ms | ease-out，可中断 |

Reduce Motion：只保留 120ms 淡入。macOS 菜单栏图标不参与动效。

### 9.5 无障碍

- **对比度**：八主题全部 ≥ AA。Terminal 次级灰 `#6F7680` → `#767E88`（4.34 → 4.85），已应用到 preset。
- **Dynamic Type**：正文与元信息同步放大；列表变高后减少可见条数、不做截断；**AX1–AX5 下底部导航转为纯图标**，热区仍 44pt。
- **状态不只靠颜色**：DRAFT / QUEUED / SENT 先读文字。
- **VoiceOver**：角色是装饰，`accessibilityHidden(true)`；列表项读「标题、状态、时间」。
- **触控**：所有可点元素 ≥ 44×44pt。

### 9.6 角色

顶部头像 24px、Agent 行 22px、Me 页 56px，均使用光学变体（大眼、粗鼻、粗嘴），否则小尺寸下五官会糊。

### 9.7 主题的变与不变

**可变（5）**：表面（底色/卡片/描边）、几何（圆角 0–22）、字体（Sans/Serif/Mono）、氛围（冷光/网格）、强调色。
**不可变（5）**：结构、图标、动效、状态语义、尺寸（44pt、行高 ±2pt）。

主题是「换心情」不是「换 App」—— 布局冻结，QA 只做 27 态而不是 8×27。

源文件：`Design/UIExplorations/ios-*.html`（生成器 `gen_ios_*.py`）。共 25 个界面：主页 · Agents · Sessions · Chat · Remote · Me · Appearance · 搜索 · 归档 · 引导 · 实况活动 ×3 · 小组件 ×3 · 会话切换 · 配对 · 分享 · 付费墙 · 设置 ×2 · 设备 · 配对 · 实验室 · 反馈。

### 10.1 界面清单

**没有独立主窗口之外的第三个窗口**：主框架是唯一常驻窗口，面板是它的快捷形态。

### 10.2 主框架

```
状态区（收件箱 · N + agent + iCloud）
捕获条（与面板同一套 composer）
列表（搜索 + 筛选 chips）│ 详情（正文 · 状态 · 排队/归档）
```

**布局是可选项，不是唯一解**。三种在设置里切换，同一套数据：

| 布局 | 结构 | 适合 |
|---|---|---|
| **三栏**（默认） | 捕获条 + 列表 + 详情 | 想法多、需要边看边改 |
| **底部输入** | 列表 + 详情，输入条贴底 | 习惯聊天式输入 |
| **侧栏** | 来源栏 + 列表 + 详情 | 已排队 / 已发送 / 归档成为分类之后 |
| ~~单列卡片~~ | — | **弃用**：一句话的条目用卡片浪费纵向空间 |

切换入口：**设置 → General → 收件箱布局**（分段控件），立即生效，记住选择。

### 10.3 设置

侧栏 11 项：General · Panel · Agents · Integrations · Remote · Sync · Usage · Pro · Updates · Lab · Feedback；**About 不放列表**，放在左下角版本号旁（点它进 About）。

**Integrations 是唯一带安装动作的页**：DSH 桥（`127.0.0.1:47823`、token 在 `~/.flowcue/dsh-bridge.json`）、Codex hooks、Claude Code。

### 10.4 状态常驻与降级

| 条件 | 形态 |
|---|---|
| `safeAreaInsets.top > 0` | 刘海：呼吸光 + 下拖收成小条 |
| 无刘海 | 菜单栏胶囊 ↔ 图标进度环 |
| 多屏 | 只在主屏显示 |
| 用户关掉菜单栏图标 | 都不出现，只留 iOS 通知 |

三者表达同一件事：**多少任务在跑、跑到哪了**。

### 10.5 错误与恢复

统一规则：**先说发生了什么，再给一个动作**；颜色只做辅助。

| 场景 | 处理 |
|---|---|
| 桥未连接 | 重启桥接 |
| 端口被占 | 换端口重启 |
| hooks 未装 | 一键安装 |
| 队列失败 | 行内标红 + 重试 |

### 10.6 首次启动与空状态

三步：欢迎（快捷键 + 通知）→ 配对（8 位码 `4F2A8C1D`）→ 默认 agent。
三个空状态都必须带动作：收件箱空（⌃⌥Space）、无 agent（安装指引）、桥未连接（重启）。

- mint `#5CD9B8` 只做状态与信号，不做品牌

## 11. Lab 与 Feedback

### 11.1 Lab（实验功能）

- 默认全关；每项一句"会发生什么"
- 底部固定说明：「开关会随版本变化。关掉即回到稳定行为」
- 入口：iOS 设置 → 实验室；macOS 设置 → Lab
- 当前实验项：语音边录边转写、智能归类、Apple Watch 审批、多 agent 并行、刘海 HUD（Mac）

### 11.2 Feedback

| 字段 | 规则 |
|---|---|
| 类型 | 问题 / 建议 / 崩溃 |
| 描述 | 多行文本 |
| 截图 | 可选 |
| 诊断日志 | 默认开，**只发版本号 + 最近 20 条日志，不含想法内容** |

隐私文案必须写死并出现在表单旁——本地优先产品的信任成本都在这一句上。

### 11.3 实验项生命周期

1. **进**：默认关闭，文案标注"实验"
2. **留**：连续 2–3 个版本无集中问题
3. **毕业**：转正，默认开启并移出 Lab
4. **下架**：反馈集中、或方向被否，直接移除并说明替代方案

Lab 不是垃圾桶：任何一项待满三个版本还没有结论，就必须做毕业生或下架的决定。

## 12. 全局约定

- 强调色 `#7E84FF`；语义色 红=失败 / 黄=等待·离线 / 绿=正常
- 状态永远「文字 + 颜色」，不单靠颜色
- 两端共用同一套 token 与状态语义，布局按平台重排
- 角色是装饰：VoiceOver 跳过，动效在 Reduce Motion 下降级
