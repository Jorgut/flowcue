Pairing a Mac

  • On the Mac, open FlowCue and choose iPhone to show the six-digit code.
  • On iPhone, open Agents → Pair a Mac and type the code.
  • Both devices must be on the same local network. VPNs and guest Wi-Fi can block discovery.
  • If discovery fails, choose Connect manually and enter the Mac's address shown in the app.

iPhone beta

  • The iPhone app is in TestFlight by invitation; there is no App Store version yet.
  • To request an invite, email hello@altn.vision with the subject “FlowCue TestFlight invite”.
  • The beta needs a Mac running FlowCue 0.1.5 or later on the same network.
  • Pro, iCloud sync and pricing are not part of the beta yet.

Mac version

  • FlowCue for Mac is a free, notarized download for macOS 14 or later, Apple silicon and Intel.
  • It reads local agent files and needs access outside the Mac App Sandbox, so it ships as a DMG rather than through the Mac App Store.
  • If macOS blocks the first launch, open System Settings → Privacy & Security and allow FlowCue.
  • Read the changelog to check which version you are running.

Data and privacy

  • Ideas are stored locally. Nothing is uploaded unless you turn on an optional sync.
  • There is no FlowCue account and no analytics SDK.
  • Read the full privacy policy.

Report a bug

Use GitHub Issues for reproducible bugs and feature requests. Include the app version, iOS or macOS version, expected behavior, and actual behavior.

Please do not post idea text, pairing codes, local file paths, or raw agent logs in a public issue. Security-sensitive reports go through the private process in SECURITY.md.
