Changelog

What changed, and when.

0.1.4 latest

2026-11-19 · macOS 14+ · Universal
  • Ideas you write, edit or share on iPhone land in the Mac inbox over your Wi-Fi.
  • Reconnecting pushes every unarchived idea; empty notes are rejected.
  • Settings now say when the Codex hook has not been trusted yet.

0.1.3

2026-11-19 · macOS 14+ · Universal
  • New replies and pending approvals from DSH arrive as system notifications, with duplicates filtered.
  • Accepts DSH’s localized approval reason, so approvals are no longer dropped.
  • Approve from iPhone: pending requests pop up within three seconds while paired.

0.1.2

2026-11-18 · macOS 14+ · Universal
  • Version handshake between iPhone and Mac over /v1/ping.
  • Built-in update: checks GitHub, downloads the DMG and verifies SHA-256.
  • Pairing and device pages show both versions and the protocol.

0.1.1

2026-11-18 · macOS 14+ · Universal
  • DSH session list and approval bridge.
  • Pro expiry published from iPhone over the LAN.
  • Signed with Developer ID and notarized by Apple.

0.1.0 first public build

2026-11-17 · macOS 14+ · Universal
  • Menu bar capture with ⌃⌥Space; save with ⌘↩.
  • Inbox with three layouts: columns, bottom composer, sidebar.
  • Local agent detection — Codex, Claude Code, DSH and others.
  • Read Claude Code and Codex sessions inside the app.
  • Pair with iPhone over your local network.
  • Signed with Developer ID and notarized by Apple.
