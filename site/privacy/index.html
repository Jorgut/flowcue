Privacy

Last updated 2026-11-17

FlowCue keeps your ideas on your own devices. There is no FlowCue account, no analytics SDK, and no server that stores your text.

What stays on your Mac

  • Ideas, drafts and queue state are stored in a local database.
  • Settings, pairing code and window positions live in your user preferences.
  • Nothing is uploaded unless you turn on iCloud sync yourself.

What the app reads locally

To list the agents installed on your machine and show their sessions, FlowCue reads local files only:

  • ~/.claude/projects — Claude Code session transcripts
  • ~/.codex — Codex configuration and hook state
  • /opt/homebrew/bin, ~/.local/bin, /Applications — to detect installed agents

These files never leave your Mac. FlowCue only reads them; it does not modify your agent configuration.

Network

  • iPhone pairing runs over your local network. There is no relay server.
  • Codex usage numbers come from the CLI you already installed, called on this Mac.
  • The only outbound request FlowCue makes is an optional update check against GitHub releases.

iCloud sync (optional)

If you enable sync, ideas are stored in your own private iCloud database via Apple CloudKit. FlowCue has no access to that data, and Apple handles it under its own terms.

Feedback

Sending feedback never happens automatically. The app puts the text on your clipboard and opens your mail client; you decide whether to send it.
