# FlowCue 小红书预热 v3（≤999 字，含标签）

## 标题

我做了个 App，专门接住点子

## 正文

最近在做一个很小的 App，叫 FlowCue，已经做了蛮久了 😅

起因是我自己的痛点：用 Codex 时，刚发出去一个想法，还没等结果，又冒出新的点子。有次我一次性发了 6 个，用语音输入法说了一大堆没组织好的话，然后等结果。

结果网络问题，6 个想法全部提交失败。

我又绞尽脑汁，把“首先、其次、然后、再一个、另外、最后、还有就是、我又突然想到……”这些口头语，重新写成一篇小作文发过去。怕再失败，还复制到了微信里。

那一刻我决定做 FlowCue。

以前我也经常在走路、坐车、睡前冒点子，有笔写本子，没笔写微信和备忘录，散落一地。回到电脑前，已经不知道哪条处理过。

FlowCue 想解决的就是这一段：手机先接住想法，Mac 再决定交给哪个 agent。

现在可以：
- 在 iPhone 快速记想法
- 回 Mac 收件箱整理、归档
- 交给 Mac 上的 Codex / DSH
- 同一 Wi-Fi 下用配对码连接，在手机看会话、继续发消息、确认审批

Mac 没开机也没关系，想法先留在手机本地，开始工作时再发送。连上后也能直接在手机上跟 agent 对话。

我在意的点：
- 不做又一个 AI 聊天框，先把「想法 → agent」走顺
- 想法默认本地，不强制注册账号
- 手机远程现在只走同一 Wi-Fi，不上传会话到第三方服务器
- 后续会做远程同步，只要电脑运行，在哪都能继续
- Codex / DSH 会话按项目文件夹分组
- 图片、语音、更多 agent 还在补

目前 TestFlight 内测，App Store 审核中，还没正式上架。
支持 Codex / DSH；Claude Code / OpenCode / Hermes 还在适配。

不是取代 coding agent，只是让“还没到电脑前的那半小时”有地方放。

想试的评论区扣「想试」，我拉你进 TestFlight。
