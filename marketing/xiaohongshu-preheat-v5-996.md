## 标题

我做了个 App，专门接住点子

## 正文

最近在做一个很小的 App，叫 FlowCue。已经做了蛮久了！😅

起因很简单：我自己的痛点。

我在用 Codex 时，刚发出去的想法还没等出结果，又会有新的点子。有一次我一次性提交了 6 个点子，用豆包语音输入法说了一大堆没组织好的话，等结果。结果网络问题，6 个想法全部提交失败！！！

我又绞尽脑汁，把 6 个想法从“首先、其次、然后、再一个、另外、最后、还有就是、我又突然想到”这些口头语，重新写成一篇小作文发给 Codex。怕再失败，还复制到了微信里。

刚才那个，是我最初决定做 FlowCue 最重要的动机。

以前我经常在走路、坐车、睡前想到点子或 bug。有笔写本子，没笔写微信和备忘录。回到电脑前，已经不知道哪条处理过。

FlowCue 想解决的就是这一段：**手机先接住所有想法，Mac 再决定交给哪个 agent。**

现在的流程大概是：

- 在 iPhone 快速记想法
- 回 Mac 收件箱整理、归档
- 需要写代码的，直接交给 Mac 上的 Codex / DSH
- 同一 Wi-Fi 下用配对码连接，在手机看会话、发消息、确认审批

Mac 没开机也没关系，想法先留在手机本地，开始工作时再发过去；连上后也能在手机上继续跟 agent 对话。

几个我比较在意的点：

- 不做又一个 AI 聊天框，先把「想法 → agent」这条路走顺
- 想法默认留在本地，不强制注册账号
- 手机远程现在只走同一 Wi-Fi，不把会话上传到第三方服务器
- 本地模式跑通后再做远程同步；只要电脑运行，在哪都能继续
- Codex / DSH 的会话按项目文件夹分组，不再混在一起
- 图片、语音、更多 agent 还在补

TestFlight 内测，App Store 审核中，还没正式上架。
支持 Codex / DSH；Claude Code / OpenCode / Hermes 还在适配。

不是要取代 coding agent，而是让「还没到电脑前的那半小时」也有地方放。

如果你也经常在手机上冒想法，回电脑又懒得整理，可以评论「想试」，我拉你进 TestFlight。
