## 正文

最近在做一个很小的 App，叫 FlowCue。

起因很简单：我经常在走路、坐车、睡前想到一些产品点子或 bug，但真正回到电脑前，想法已经散了。以前是备忘录、微信文件传输助手、聊天框到处丢，最后自己都不知道哪条已经处理过。

FlowCue 想解决的就是这一段：

**手机先接住想法，Mac 再决定交给哪个 agent。**

现在的流程大概是：

1. 在 iPhone 上快速记一条想法
2. 回到 Mac 的 FlowCue 收件箱，整理、归档
3. 需要写代码的，直接交给 Mac 上的 Codex / DSH
4. 手机和 Mac 在同一 Wi-Fi 下，还能用配对码连起来，在手机上查看会话、继续发消息、确认审批

几个我比较在意的点：

- 不做又一个 AI 聊天框，先把“想法 → agent”这条路走顺
- 想法默认留在本地，不强制注册账号
- 手机远程只走同一 Wi-Fi，不上传会话到第三方服务器
- Codex / DSH 的会话可以按项目文件夹分组，不再混在一起
- 现在还在补图片、语音和更多 agent 的适配

目前状态：

- TestFlight 内测中
- App Store 正在审核，还没正式上架
- 支持 Codex / DSH 的本地会话
- Claude Code / OpenCode / Hermes 还在适配

不是要取代 coding agent，而是让“还没到电脑前的那半小时”也有地方放。

如果你也经常在手机上冒想法，回电脑又懒得重新整理，可以评论“想试”，我拉你进 TestFlight。
