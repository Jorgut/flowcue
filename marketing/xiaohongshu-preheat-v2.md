## 正文

最近在做一个很小的 App，叫 FlowCue。其实已经做了蛮久了！😅

起因很简单，是源于我自己的痛点。

一个是我在使用 Codex 的时候，刚发出去的想法还没等出结果，又会有新的点子，一个两个三个。有一次我一次性提交了 6 个点子，用豆包语音输入法说了一大堆没有过脑子完整组织的想法，然后静静等结果。结果网络问题，我所有的想法都提交失败！！！

然后我又绞尽脑汁，把之前的 6 个想法从“首先、其次、然后、再一个、另外、最后、还有就是、以及我又突然想到、是否可以、能不能增加”这些口头语，重新写成一篇小作文发给 Codex。为了防止半路又失败，我还把内容复制粘贴到微信里。

刚才那个，是我最初决定做 FlowCue 最重要的动机。

其实以前我也经常在走路、坐车、睡前想到一些产品点子或 bug。身边有笔就写在本子上，没笔就写在微信和备忘录里，散落得到处都是。等真正回到电脑前，想法已经散了一地。以前是备忘录、微信文件传输助手、聊天框到处丢，最后自己都不知道哪条已经处理过。

FlowCue 想解决的就是这一段：**手机先接住所有想法，Mac 再决定交给哪个 agent。**

现在的流程大概是：

- 在 iPhone 上快速记一条想法
- 回到 Mac 的 FlowCue 收件箱，整理、归档
- 需要写代码的，直接交给 Mac 上的 Codex / DSH
- 手机和 Mac 在同一 Wi-Fi 下，用配对码连起来，在手机上查看会话、继续发消息、确认审批

如果 Mac 没开机也没关系，想法可以保存在手机 App 的本地。等你开始工作的时候，直接在手机上点击发送移交给 Mac；连上之后，也可以直接在手机上跟 agent 对话。

几个我比较在意的点：

- 不做又一个 AI 聊天框，先把「想法 → agent」这条路走顺
- 想法默认留在本地，不强制注册账号
- 手机远程现在只走同一 Wi-Fi，不把会话上传到第三方服务器
- 等本地网络模式完全跑通后，会做远程同步：只要电脑在运行，不管你在哪，都可以通过手机继续工作
- Codex / DSH 的会话按项目文件夹分组，不再混在一起
- 现在还在补图片、语音，以及更多 agent 的适配

目前状态：

- TestFlight 内测中
- App Store 正在审核，还没正式上架
- 支持 Codex / DSH 的本地会话
- Claude Code / OpenCode / Hermes 还在适配

不是要取代 coding agent，而是让「还没到电脑前的那半小时」也有地方放。

如果你也经常在手机上冒想法，回电脑又懒得重新整理，可以评论「想试」，我拉你进 TestFlight。
